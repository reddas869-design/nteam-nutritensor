# Offline starter fruit catalog

Eight raw-fruit records were retrieved directly from the USDA FoodData Central API on 2026-10-18. The API's documented public demonstration credential was used for this one-time bounded retrieval; runtime lookup needs no key or network.

| App name | FDC ID | Source preparation |
|---|---|---|
| Apple | 171688 | Raw, with skin |
| Banana | 173944 | Raw |
| Tangerine | 169105 | Mandarin oranges, raw |
| Orange | 169097 | Raw, all commercial varieties |
| Strawberry | 167762 | Raw |
| Mango | 169910 | Raw |
| Avocado | 171705 | Raw, all commercial varieties |
| Pineapple | 169124 | Raw, all varieties |

Source detail links follow `https://fdc.nal.usda.gov/food-details/<FDC-ID>/nutrients` and are preserved in every record. The original descriptions and nutrient rows are retained in `backend/nutritensor/resources/fruit_sources.json`. The app-normalized records are in `fruit_catalog.json` in the same directory. Tests reconstruct the nutrient values from the retained source and verify equality, source identity, and unambiguous aliases.

English/Bengali common names, app display names, and edible-portion instructions are app metadata; they are not claimed as USDA classifications. Nutrient quantities were normalized through the existing importer, not generated by the LLM. Values remain per 100 g edible portion. They are general reference records, not laboratory measurements of the photographed fruit or a guarantee for every variety, ripeness, or preparation.

Install or extend the local catalog with `python scripts/install_fruit_catalog.py --merge`. Existing local records with the same FDC IDs win; the command does not overwrite operator-reviewed values. The server reloads its catalog on restart. Other foods require reviewed imported records and unambiguous aliases before automatic mapping can succeed.
